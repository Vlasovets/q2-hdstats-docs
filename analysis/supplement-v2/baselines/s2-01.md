# Getting started - analysis of the Atacama top-15 ASV data

(sec:lowdim)=

The Atacama top-15 ASV data set is a real reduced table derived from the processed 54-sample ASV table. One sample, `YUN1005.1.1`, has zero counts across all 15 selected ASVs. Since a row with no observed counts contains no information about ratios among the selected ASVs, this sample is removed before transformation and model fitting. The resulting example has $n=53$ samples and $p=15$ ASVs. The reproducible workflow ranks ASVs on these 53 analysis samples by prevalence, defined as the number of samples with a non-zero count. Ties are resolved by total relative abundance, then total count, then feature identifier. Both table sizes use this same ranking.

The top-15 ASV table is then represented in two log-ratio-like coordinate systems for the analyses below. For prediction with **q2-classo**, we use the standard CLR implementation with zero replacement value `--p-coef 0.5`. For graphical model estimation with **q2-gglasso**, we use the modified CLR (mCLR), which keeps zero entries at zero and transforms only the positive entries as described in Section {ref}`S1.1 <sec:compositional-data>`. The regression workflow uses a 39/14 training--held-out split, so the same q2-classo CLR transformation is applied separately to the training and held-out count tables.

(sec:lowdim-regression)=
## Elevation prediction with q2-classo

The regression results in this supplement use the GitHub version of **c-lasso** at commit [`d22da8d5`](https://github.com/bio-datascience/c-lasso/commit/d22da8d5ea54eb499de2fce82fa6c0e1f0c2dcc0) (merged PR 60), through **q2-classo** in QIIME 2.

The CLR-transformed top-15 ASV data set is used for log-contrast prediction with **q2-classo**. Elevation is the response because it is complete in the 53-sample table and captures the broad environmental gradient along the Atacama transects {cite:p}`knief2020tracing`. The ASV coefficients are constrained to sum to zero, so the fitted model should be read as a prediction rule based on log-ratios among the selected ASVs.

**Example:**

```bash
# R3: concomitant least-squares c-lasso with 5-fold CV and 1SE selection
qiime classo regress \
    --i-features atacama-top15-train-53-clr.qza \
    --m-y-file elevation-train-53-metadata-q2.tsv \
    --m-y-column elevation \
    --p-no-path \
    --p-no-stabsel \
    --p-no-lamfixed \
    --o-result atacama-top15-elevation-r3-cv.qza

qiime classo predict \
    --i-features atacama-top15-test-53-clr.qza \
    --i-problem atacama-top15-elevation-r3-cv.qza \
    --o-predictions atacama-top15-elevation-r3-test-predictions.qza

# R3 stability selection with the same training data
qiime classo regress \
    --i-features atacama-top15-train-53-clr.qza \
    --m-y-file elevation-train-53-metadata-q2.tsv \
    --m-y-column elevation \
    --p-no-path \
    --p-no-cv \
    --p-no-lamfixed \
    --p-stabsel-seed 1 \
    --p-stabsel-b 100 \
    --p-stabsel-q 4 \
    --p-stabsel-threshold 0.3333333333333333 \
    --o-result atacama-top15-elevation-r3-stabsel-q4-b100-threshold-third.qza

qiime classo predict \
    --i-features atacama-top15-test-53-clr.qza \
    --i-problem atacama-top15-elevation-r3-stabsel-q4-b100-threshold-third.qza \
    --o-predictions atacama-top15-elevation-r3-stabsel-threshold-third-test-predictions.qza
```

## Vegetation classification with q2-classo

The same CLR-transformed top-15 ASV data set can also be used for binary classification. As a simple ecological endpoint, we classify whether vegetation was recorded at the sampling site. In the 53-sample top-15 ASV table, the `vegetation` metadata column contains 35 samples with vegetation and 18 without vegetation. This endpoint is preferable to an arbitrary median split of a continuous covariate because it is already binary and summarizes visible plant cover along the same environmental gradient.

**Example:**

```bash
qiime classo classify \
    --i-features atacama-top15-train-53-clr.qza \
    --m-y-file vegetation-train-53-metadata-q2.tsv \
    --m-y-column vegetation \
    --p-no-path \
    --p-no-stabsel \
    --p-no-lamfixed \
    --o-result atacama-top15-vegetation-classification-cv.qza

    --i-features atacama-top15-test-53-clr.qza \
    --i-problem atacama-top15-vegetation-classification-cv.qza \
    --o-predictions atacama-top15-vegetation-classification-cv-test-predictions.qza
```

(sec:lowdim-gglasso)=
## Graphical model workflow with q2-gglasso

Conditional association structure is estimated from the same top-15 ASV data set without specifying a response variable. The ASVs are modeled jointly through a sparse precision matrix. The empirical mCLR correlation matrix provides the input summary, and **q2-gglasso** is then used to compare three increasingly structured estimators: an ASV-only single graphical lasso, a mixed graph in which measured Atacama covariates are appended to the ASV table, and a sparse plus low-rank model in which unmeasured shared variation is represented by a latent component ({ref}`S8 <fig:top15-gglasso-four-panel>`).

All three analyses use the scaled covariance calculated by `calculate-covariance` with `--p-method scaled` and `--p-bias`. Thus the input matrix is on a correlation scale and uses the likelihood normalization by $n=53$. Model selection is performed over the same candidate $\lambda_1$ path using the eBIC criterion in {eq}`eq:ebic` with $\gamma=0.01$. We use this weak additional graph-size penalty because the introductory example is low-dimensional: the plain ASV graph has only 15 variables, and the mixed graph has 21 variables after adding the six curated covariates.

(sec:lowdim-sgl)=
## Microbial association network estimation with the single graphical lasso

The single graphical lasso (SGL) estimates a sparse precision matrix from the top-15 ASV table alone. A non-zero off-diagonal entry of the estimated precision matrix is interpreted as a conditional association between two ASVs after accounting for the remaining ASVs in the same table. In {ref}`S8 <fig:top15-gglasso-four-panel>`, the SGL estimate maps the dense empirical mCLR correlation matrix to a sparse conditional association network.

**Example:**

```bash
# empirical mCLR correlation of the top-15 ASV table
qiime gglasso calculate-covariance \
    --i-table atacama-top15-53-mclr.qza \
    --o-covariance-matrix atacama-top15-53-mclr-correlation.qza

# ASV-only SGL with eBIC model selection
qiime gglasso solve-problem \
    --i-covariance-matrix atacama-top15-53-mclr-correlation.qza \
    --p-n-samples 53 \
    --p-no-latent \
    --p-lambda1-path 1.0 0.9 0.8 0.7 0.6 0.5 0.4 0.3 0.2 0.15 0.1 0.075 0.05 0.035 0.025 \
        0.015 0.01 \
    --o-solution atacama-top15-53-sgl-ebic-gamma001.qza
```

The selected SGL edge list contains 13 ASV--ASV edges: ASV-1--ASV-3, ASV-1--ASV-6, ASV-1--ASV-8, ASV-1--ASV-11, ASV-3--ASV-4, ASV-3--ASV-8, ASV-4--ASV-9, ASV-6--ASV-7, ASV-6--ASV-9, ASV-6--ASV-11, ASV-7--ASV-9, ASV-11--ASV-13, and ASV-12--ASV-15. The selected graph retains several of the strongest empirical correlation pairs, including ASV-7--ASV-9, ASV-11--ASV-13, ASV-3--ASV-4, and ASV-12--ASV-15, while shrinking the dense background of weaker marginal correlations to zero. Most retained edges are positive; the negative partial correlations are ASV-1--ASV-3, ASV-1--ASV-8, and ASV-4--ASV-9.

(sec:lowdim-mixed-graph)=
## Covariate-adjusted mixed graphical model

The covariate-adjusted graph includes measured sample variables alongside the ASVs. The covariates used here are elevation, pH, average soil relative humidity, average soil temperature, percent vegetation cover, and log-transformed extract concentration. They are appended to the transformed ASV table with `transform-features`; numeric metadata are standardized by **q2-gglasso**. Three humidity and temperature entries are missing in the 53-sample table and are mean-imputed before this step. Because these variables represent broad environmental or technical gradients that are likely associated with most or all ASVs at this scale, the mixed model uses a weaker penalty for covariate incident edges, implemented as weight 0.05 on these covariate labels. This allows measured covariates to absorb shared variation without forcing the ASV--ASV block to become dense. The estimated mixed graph is shown in the third panel of {ref}`S8 <fig:top15-gglasso-four-panel>`, with ASVs and covariates represented in the same precision matrix.

**Example:**

```bash
# append standardized measured covariates to the mCLR ASV table
qiime gglasso transform-features \
    --i-table atacama-top15-prevalence-53-table.qza \
    --i-taxonomy atacama-taxonomy.qza \
    --m-sample-metadata-file atacama-top15-53-curated-metadata-for-gglasso.tsv \
    --p-transformation mclr \
    --p-add-metadata \
    --o-transformed-table atacama-top15-53-mclr-with-curated-covariates.qza

qiime gglasso calculate-covariance \
    --i-table atacama-top15-53-mclr-with-curated-covariates.qza \
    --o-covariance-matrix atacama-top15-53-mclr-curated-covariate-correlation.qza

qiime gglasso solve-problem \
    --i-covariance-matrix atacama-top15-53-mclr-curated-covariate-correlation.qza \
    --p-n-samples 53 \
    --p-no-latent \
    --p-lambda1-path 1.0 0.9 0.8 0.7 0.6 0.5 0.4 0.3 0.2 0.15 0.1 0.075 0.05 0.035 0.025 \
        0.015 0.01 \
    --p-weights elevation 0.05 ph 0.05 average-soil-relative-humidity 0.05 \
        average-soil-temperature 0.05 percentcover 0.05 log10-extract-concen 0.05 \
    --o-solution atacama-top15-53-mixed-curated-covariates-weight005-ebic-gamma001.qza
```

After adding the measured covariates, the ASV--ASV edge list is reduced to ASV-6--ASV-7, ASV-7--ASV-9, ASV-11--ASV-13, and ASV-12--ASV-15. This reduction is consistent with adjustment for broad measured gradients: associations that can be represented through covariate incident edges are no longer assigned to the ASV--ASV block. The covariate part of the graph also connects to the q2-classo elevation analysis above. In particular, ASV-14 has the strongest ASV--elevation partial-correlation edge in the mixed graph. ASV-14 also has an intermediate selection probability of 0.38 in the stability-selection elevation analysis and is retained at the illustrative $1/3$ threshold. This edge is positive in the fitted partial correlation matrix, whereas its sign should still be read as a conditional graph sign rather than as a univariate abundance--elevation statement. The recurrence of the same ASV--covariate signal across prediction and graphical modeling provides a useful cross-model comparison.

(sec:lowdim-slr)=
## Latent variable graphical model

The ASV table without measured covariates is also analyzed with a latent-variable graphical model. This model assesses whether residual dependence among the ASVs can be decomposed into a sparse conditional network and a low-rank component representing unmeasured shared variation. The estimator uses the same ASV-only empirical matrix as the SGL analysis, but `solve-problem` is called with `--p-latent`. eBIC model selection estimates a rank-one latent adjustment, and the right panel of {ref}`S8 <fig:top15-gglasso-four-panel>` appends the corresponding LV1 loadings to the sparse ASV block. The display summarizes adjustment for an unmeasured sample-level gradient.

**Example:**

```bash
qiime gglasso solve-problem \
    --i-covariance-matrix atacama-top15-53-mclr-correlation.qza \
```
