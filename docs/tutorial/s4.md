# MOSHPIT cocoa-bean fermentation example

The final applied classification example uses the cocoa-bean fermentation data of {cite:t}`lima2021cocoa`, featured in the [QIIME 2 MOSHPIT tutorial](https://moshpit.qiime2.org/en/latest/chapters/tutorials/cocoa/cocoa-intro/). The reads are deposited under NCBI BioProject PRJNA552479. MOSHPIT retrieves the raw paired-end reads and metadata from the NCBI Sequence Read Archive using **q2-fondue** {cite:p}`ziemski2022fondue`, classifies the reads with Kraken 2, and uses Bracken to estimate species-level abundance. We use the resulting `FeatureTable[Frequency]`. The data contain 14 fermentation samples, seven each from Forasteiro and Hybrid beans, measured at the matched time points 0, 24, 48, 72, 96, 120, and 144 hours. The unfiltered table has 10,927 species-level features. Its small sample size supports workflow demonstration but does not validate cocoa-bean variety effects.

Before using the bean-type labels, we retain species observed in all 14 samples and contributing at least 50,000 reads across the table. This single prevalence-and-abundance filter retains 61 species, so that the resulting classification problem remains high-dimensional ($p=61>n=14$). The filter is applied to the complete feature table because it is independent of the outcome; the subsequent model fitting and CLR transformations respect the training--test split described below. Figure {ref}`S24 <fig:bracken-data>` shows the resulting CLR table, where the strong temporal and bean-type structure also motivates a cautious interpretation of prediction results.

**Example:**

```bash
qiime feature-table filter-features \
    --i-table bracken-species-raw.qza \
    --p-min-samples 14 \
    --p-min-frequency 50000 \
    --o-filtered-table bracken-species-prev14-total50k.qza
```
