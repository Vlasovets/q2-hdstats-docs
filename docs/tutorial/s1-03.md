(sec:graphical)=
# General graphical model estimation with **q2-gglasso**

Graphical models represent multivariate dependence through a graph whose nodes are random variables and whose missing edges encode conditional independence statements {cite:p}`lauritzen1996graphical`. For a multivariate Gaussian random vector, these statements have a particularly direct form: if $\Sigma$ is the covariance matrix and $\Theta=\Sigma^{-1}$ is the precision matrix, then $\Theta_{ij}=0$ if and only if variables $i$ and $j$ are conditionally independent given all remaining variables {cite:p}`dempster1972covariance`. Thus a Gaussian graphical model can be estimated by finding the structural zeros of the precision matrix. In turn, the non-zero off-diagonal entries are interpreted as "edges" between variables, allowing the fitted model to be represented as a sparse association network.

This classical covariance-selection problem became central in high-dimensional statistics once the number of variables $p$ could exceed the number of samples $n$. In that setting the empirical covariance is singular and unregularized maximum likelihood is not available. Sparse inverse-covariance estimators therefore add regularization to select a graph, either through neighborhood selection {cite:p}`meinshausen2006high` or through penalized likelihood, as in the graphical lasso {cite:p}`yuan2007model,banerjee2008model,friedman2008sparse`. The underlying estimation problems are convex optimization problems that can be efficiently solved with a variety of methods. The Gaussianity assumption about the underlying data can also be relaxed through rank-based nonparanormal graphical models {cite:p}`xue2012regularized`.

For microbial sequencing data, {cite:t}`kurtz2015sparse` brought this viewpoint into compositional microbiome network inference with SPIEC-EASI, emphasizing that microbial association networks should be estimated after an appropriate log-ratio transformation rather than from raw correlations of relative abundances. Consequently, graphical modeling for microbiome data starts from the transformed table $Z\in\mathbb{R}^{n\times p}$ defined above. In **q2-gglasso**, $Z$ is converted into an empirical covariance $\widetilde{S}$ or, after scaling, a correlation matrix $S$. The CLR and mCLR transformations center log-ratios within each sample; they do not center each feature across samples. Thus the empirical covariance is computed after subtracting feature-wise sample means. With $\bar z = n^{-1}Z^\top\mathbf{1}_n \in \mathbb{R}^p$ and $Z_c = Z-\mathbf{1}_n\bar z^\top$,

```{math}
:label: eq:covariance

\widetilde{S} =
\frac{1}{n-\delta} Z_c^\top Z_c,
\qquad
\delta =
\begin{cases}
0, & \texttt{-{}-p-bias}=\texttt{True},\\
1, & \texttt{-{}-p-bias}=\texttt{False}.
\end{cases}
```

**q2-gglasso** uses `--p-bias True` by default, corresponding to division by $n$. By default, it then scales this covariance to a correlation matrix,

```{math}
:label: eq:cov_scaling

S = D^{-1/2} \widetilde{S} D^{-1/2},
\qquad
D = \operatorname{diag}(\widetilde{S}),
```

or, equivalently, $S_{jk}=\widetilde{S}_{jk}/
\sqrt{\widetilde{S}_{jj}\widetilde{S}_{kk}}$. The unscaled covariance can be requested with `--p-method unscaled`. This scaling is not only numerical: for sparse large covariance models, estimating the non-zero off-diagonal entries of a correlation or inverse-correlation matrix can enjoy a faster convergence rate because the diagonal variance terms do not have to be estimated as part of the sparse target {cite:p}`lam2009sparsistency`. The resulting matrix is stored as a pairwise feature artifact and passed to the general graphical lasso solvers inherited from **GGLasso** {cite:p}`Schaipp2021`.

**Example:**

```bash
# transformed table Z -> covariance or correlation S
qiime gglasso calculate-covariance \
    --i-table Z-gglasso-clr.qza \
    --o-covariance-matrix S.qza
```

(sec:sgl)=
## Association network estimation with the single graphical lasso (SGL)

For a single homogeneous data set, the aim is to estimate one sparse association network among $p$ transformed variables. The single graphical lasso (SGL) does this by penalized maximum likelihood with a sparsity parameter $\lambda_1$; the selection of $\lambda_1$ is discussed below in Section {ref}`S1.3 <sec:gglasso-model-selection>`. The estimator is

```{math}
:label: eq:sgl

\min_{\Theta\in \mathbb{S}^{p}_{++}} \;
-\log\det \Theta+ \langle S, \Theta\rangle + \lambda_{1} \lVert \Theta \rVert_{1,\mathrm{od}},
```

where $\mathbb{S}^{p}_{++}$ denotes the cone of symmetric positive definite $p \times p$ matrices, $\langle A,B\rangle = \operatorname{tr}(A^{\top}B)$ is the trace inner product, and $\lVert \Theta \rVert_{1,\mathrm{od}} = \sum_{i \neq j} |\Theta_{ij}|$ is the $\ell_1$ norm of the off-diagonal (od) entries. The first two terms are the negative Gaussian log-likelihood up to constants; the penalty induces sparsity while leaving the diagonal unpenalized. A non-zero off-diagonal entry of the solution, $\widehat{\Theta}_{ij}\ne 0$, is read as an edge between features $i$ and $j$ in the fitted conditional dependence graph. Edge signs and weights are commonly displayed as partial correlations,

```{math}
:label: eq:partialcor

\widehat{\rho}_{ij}
= - \frac{\widehat{\Theta}_{ij}}
{\sqrt{\widehat{\Theta}_{ii} \widehat{\Theta}_{jj}}},
\qquad i \neq j .
```

In the microbiome workflow considered here, these $p$ variables are the transformed microbial features in $Z$. The estimator is available in **q2-gglasso** through the `solve-problem` action.

**Example:**

```bash
# solving SGL
qiime gglasso solve-problem \
    --i-covariance-matrix S.qza \
    --p-n-samples <value> \
    --p-lambda1-path <value> \
    --o-solution fit-sgl.qza
```

(sec:adaptive)=
## Mixed graphical lasso and adaptive penalization

In many applications, the scientific question is not only whether the primary variables are conditionally associated with each other, but also how these associations change after measured covariates are included in the same graph. Mixed graphical models provide a statistical language for such joint models. Classical conditional Gaussian models already combine continuous and discrete variables in one graphical model {cite:p}`lauritzen1996graphical`, and modern high-dimensional extensions use node-conditional exponential-family or pairwise formulations for continuous, binary, categorical, and count-valued nodes {cite:p}`yang2015graphical,lee2015learning,chen2015selection,cheng2017high`. Software such as **mgm** made these ideas broadly accessible for estimating high-dimensional mixed graphical models in practice {cite:p}`haslbeck2020mgm`.

A recurring practical issue in such joint models is that a single global penalty need not be appropriate for all potential edges. Edges among the primary variables, edges between primary variables and covariates, and edges among covariates can differ in scale, dimension, and prior plausibility. Mixed graphical model implementations therefore often use type-specific, block-specific, or edge-specific regularization parameters. In biological applications, this principle can also be used to incorporate external knowledge: prior-informed mixed graphical models change the effective penalty for edges supported by pathway, interaction, or other database evidence {cite:p}`manatakis2018pimgm`.

The **q2-gglasso** workflow uses a simple Gaussian version of this idea. In the present microbiome setting, the primary block is the transformed microbial table $Z$ and the covariates may include environmental measurements, host phenotypes, clinical variables, or additional molecular assays. Let $U\in\mathbb{R}^{n\times q}$ denote these measured non-compositional covariates and let $V=[Z\; U]\in\mathbb{R}^{n\times(p+q)}$ denote the joint design. After the microbial features have been represented on a log-ratio scale and the covariates have been scaled as appropriate, one forms an empirical covariance or correlation matrix $S_V\in\mathbb{R}^{(p+q)\times(p+q)}$. A graphical lasso fit to $S_V$ then estimates a joint precision matrix whose blocks correspond to microbe--microbe, microbe--covariate, and covariate--covariate conditional associations.

Different shrinkage levels can be represented by a non-negative symmetric mask $M=(m_{ij})\in\mathbb{R}^{(p+q)\times(p+q)}_{\ge0}$ and the resulting entrywise penalty matrix $\Lambda=\lambda_1 M$, giving the adaptive graphical lasso

```{math}
:label: eq:adaptive

\min_{\Theta\in \mathbb{S}^{p+q}_{++}} \;
-\log\det \Theta+ \langle S_V, \Theta\rangle
+ \lVert \Lambda \odot \Theta\rVert_{1,\mathrm{od}} ,
```

where $\odot$ denotes elementwise multiplication. The ordinary SGL estimator is recovered when the off-diagonal entries of $M$ equal one. Block- or feature-specific choices of $M$ instead allow the analyst to penalize, for example, primary--covariate edges differently from primary--primary edges. Such joint networks are useful as sensitivity analyses: an edge among the primary variables that disappears after adding a measured covariate is no longer estimated as a direct conditional association within the enlarged feature set.

This mixed graphical lasso formulation is available in **q2-gglasso** through pre-estimation transformation and scaling. Sample metadata can be appended during `transform-features`, and numeric metadata are standardized by default. Adaptive penalty multipliers are exposed through `solve-problem` as label--weight pairs; the plugin constructs the corresponding penalty mask from feature labels. Thus, for the present application, **q2-gglasso** supports joint microbial--covariate networks by normalizing first and using optional label-based penalty multipliers.

**Example:**

```bash
# adding covariates at the transform step
qiime gglasso transform-features \
    --i-table counts.qza \
    --i-taxonomy taxonomy.qza \
    --p-transformation clr \
    --m-sample-metadata-file metadata.tsv \
    --p-add-metadata --p-scale-metadata \
    --o-transformed-table Z-with-metadata.qza

qiime gglasso calculate-covariance \
    --i-table Z-with-metadata.qza \
    --o-covariance-matrix S-with-metadata.qza

# solving mixed graphical lasso with label-based penalty multipliers
qiime gglasso solve-problem \
    --i-covariance-matrix S-with-metadata.qza \
    --p-n-samples <value> --p-lambda1-path <value> \
    --p-weights <label weight ...> \
    --o-solution fit-adaptive.qza
```

(sec:mgl)=
## Multiple graphical lasso problems

Many studies compare related instances, such as time points, treatment groups, experimental conditions, or study sites. Estimating one graph per instance independently discards shared structure, while pooling all samples hides condition-specific associations. The multiple graphical lasso of {cite:t}`danaher2014joint` estimates $K$ precision matrices jointly from covariance or correlation matrices $S^{(1)},\ldots,S^{(K)}$ and sample sizes $n^{(1)},\ldots,n^{(K)}$:

```{math}
:label: eq:mgl

\min_{\Theta^{(1)},\dots,\Theta^{(K)} \succ 0} \;
\sum_{k=1}^{K} n^{(k)}
\Big\{ -\log\det \Theta^{(k)} + \langle S^{(k)}, \Theta^{(k)} \rangle \Big\}
+ \lambda_{1} \sum_{k=1}^{K} \lVert \Theta^{(k)} \rVert_{1,\mathrm{od}}
+ \lambda_{2}\, \mathcal{P}\!\left(\Theta^{(1)},\dots,\Theta^{(K)}\right).
```

Here $\Theta^{(k)} \in \mathbb{S}^{p}_{++}$ is the precision matrix of group $k$, each group contributes its own likelihood term weighted by $n^{(k)}$, $\lambda_1$ penalizes each group's edges separately as in {eq}`eq:sgl`, and $\mathcal{P}$ couples the $K$ solutions with strength $\lambda_2$. Two choices of $\mathcal{P}$ are available:

```{math}
:label: eq:ggl

\begin{aligned}\text{Group graphical lasso (GGL):}\quad
\mathcal{P} &= \sum_{i \neq j} \Big( \textstyle\sum_{k} (\Theta^{(k)}_{ij})^{2} \Big)^{1/2},
\end{aligned}
```





```{math}
:label: eq:fgl

\begin{aligned}
\text{Fused graphical lasso (FGL):}\quad
\mathcal{P} &= \sum_{k < k'} \sum_{i \neq j} \big| \Theta^{(k)}_{ij} - \Theta^{(k')}_{ij} \big| .
\end{aligned}
```

GGL couples edge presence across conditions while allowing edge weights to differ. FGL penalizes edge-weight differences directly and is most natural when the groups have a meaningful ordering, such as time.

For microbiome applications, these instances may be habitats, body sites, treatment groups, or repeated time points. This estimator is available in **q2-gglasso** through the `solve-problem` action when the covariance input contains several instances. The argument `--p-reg GGL` selects the group penalty and `--p-reg FGL` selects the fused penalty. For partially shared feature sets, the non-conforming GGL formulation uses a bookkeeping array to map matched feature pairs across instances. **q2-gglasso** provides `build-groups` for constructing this array; in the current interface it must be passed to `solve-problem` as `--p-group-array`.

**Example:**

```bash
# solving MGL problem
qiime gglasso solve-problem \
    --i-covariance-matrix S.qza \
    --p-n-samples <value> --p-n-samples <value> --p-n-samples <value> \
    --p-reg GGL \
    --p-lambda1-path <value> \
    --p-lambda2-min <value> --p-lambda2-max <value> --p-n-lambda2 <value> \
    --o-solution fit-mgl.qza
```

(sec:slr)=
## Latent variable graphical models

The mixed graphical lasso in Section {ref}`S1.3 <sec:adaptive>` adjusts a graph for covariates that were actually measured. In practice, however, additional shared effects may be unobserved or unavailable to the analysis. The latent-variable graphical lasso asks whether one can still adjust, at least partially, for such unmeasured covariates. The key assumption is that a small number of latent factors can induce broad covariance structure across many observed variables, while the conditional network among the observed variables remains sparse. This leads to the sparse plus low-rank decomposition of {cite:t}`chandrasekaran2010latent`:

```{math}
:label: eq:slr

\min_{\Theta_{S},\, L} \;
-\log\det(\Theta_{S} - L) + \langle S, \Theta_{S} - L \rangle
+ \lambda_{1} \lVert \Theta_{S} \rVert_{1,\mathrm{od}} + \mu_{1} \lVert L \rVert_{\star}
\quad
\text{s.t. } \Theta_{S}-L\in\mathbb{S}^{p}_{++}, \; L\succeq0 .
```

The fitted observed precision matrix is $\widehat{\Theta}=\widehat{\Theta}_{S}-\widehat L$. The sparse block $\widehat{\Theta}_S$ carries the network edges of interest after adjustment for latent structure, while $\widehat L$ absorbs broad covariance patterns that are consistent with unmeasured shared factors. The method therefore does not recover the missing covariates themselves. Rather, it provides a regularized graphical model in which the estimated sparse network is separated from a low-rank component. The nuclear norm $\lVert L \rVert_{\star}=\sum_i\sigma_i(L)$ penalizes the spectrum of $L$; because $L\succeq0$, its singular values are its eigenvalues. A larger $\mu_1$ therefore shrinks more eigenvalues to zero and tends to reduce $\mathop{\mathrm{rank}}(\widehat L)$. In the released **GGLasso** backend used here, rank is an output controlled indirectly through $\mu_1$ rather than a fixed input.

The fitted low-rank block admits the factorization

```{math}
:label: eq:lfactor

\widehat L = \sum_{k=1}^{r_L} \ell_k \ell_k^{\top},
\qquad r_L = \mathop{\mathrm{rank}}(\widehat L) \ll p ,
```

where $\ell_k \in \mathbb{R}^p$ describes how latent factor $k$ loads on the observed features.

In the present microbiome setting, such latent factors may represent unmeasured environmental, technical, or host-level effects, and sparse plus low-rank models have been used to separate microbial associations from latent effects {cite:p}`kurtz2019disentangling`. This estimator is available in **q2-gglasso** through `solve-problem` with `--p-latent`. The plugin also exposes a PCA visualizer for latent fits; this summarizes the low-rank block graphically and should not be interpreted as a separate inferential procedure.

**Example:**

```bash
# solving latent-variable graphical lasso
qiime gglasso solve-problem \
    --i-covariance-matrix S.qza \
    --p-n-samples <value> --p-latent \
    --p-lambda1-path <value> --p-mu1-path <value> \
    --o-solution fit-slr.qza
```

(sec:gglasso-model-selection)=
## Model selection

All graphical-lasso variants above are penalized estimators. Their use therefore requires a choice of sparsity level, and in the multiple or latent formulations a choice of coupling or low-rank regularization as well. In **q2-gglasso**, SGL selection is carried out over a path of $\lambda_1$ values, latent SGL over a grid in $(\lambda_1,\mu_1)$, and MGL over a grid in $(\lambda_1,\lambda_2)$. If all relevant regularization parameters are supplied as single values, one fixed-penalty fit is computed. Otherwise, model selection uses the extended Bayesian information criterion (eBIC) of {cite:t}`foygel2010extended`. For a single graphical model estimate $\widehat\Theta$ with edge set $E$,

```{math}
:label: eq:ebic

\mathrm{eBIC}_{\gamma}(\widehat\Theta)
= n\big\{\operatorname{tr}(S\widehat\Theta) - \log\det\widehat\Theta\big\}
\;+\; |E| \log n \;+\; 4\gamma\,|E| \log p ,
```

where the first term is the negative Gaussian log-likelihood up to constants and $\gamma \in [0,1]$ sets an additional penalty on graph size. At $\gamma = 0$ this becomes the ordinary BIC; larger $\gamma$ selects sparser graphs. The selected penalty can change substantially with $\gamma$, so $\gamma$ should be reported alongside the selected $\lambda_1$ and, where applicable, $\lambda_2$ or $\mu_1$. When no explicit $\lambda_1$ path or min--max grid is supplied, the local **q2-gglasso** implementation expands to a default logarithmic path. This means that an apparently underspecified call can still run a model-selection procedure rather than one fixed-penalty fit; analogous default grids are used for $\lambda_2$ in MGL and for $\mu_1$ in latent fits.

**Example:**

```bash
# solving problem for a particular lambda
qiime gglasso solve-problem \
    --i-covariance-matrix S.qza \
    --p-n-samples <value> \
    --p-lambda1-path <single value> \
    --o-solution fit-single.qza

# model selection over a lambda path
qiime gglasso solve-problem \
    --i-covariance-matrix S.qza \
    --p-n-samples <value> \
    --p-lambda1-min <value> --p-lambda1-max <value> --p-n-lambda1 <value> \
    --p-path-scale linear \
    --p-gamma <value> \
    --o-solution fit-selected.qza
```

(sec:gglasso-inference)=
## Inference

The fitted **q2-gglasso** networks should be interpreted as regularized graph estimates. The plugin does not provide confidence intervals, edge-level $p$-values, or multiplicity-adjusted tests for selected edges. As in sparse log-contrast prediction, edge selection is part of the estimation procedure: the event that an edge appears in the fitted graph is itself data-dependent. Uncertainty statements therefore have to account for regularization, model selection, high-dimensional bias, and the scale on which $S$ was constructed.

There is active theory for inference on high-dimensional Gaussian precision matrices, including de-sparsified graphical lasso and asymptotically efficient entrywise estimators {cite:p}`jankova2015confidence,ren2015asymptotic`. These results provide useful reference points for simpler Gaussian graphical models. They do not directly deliver routine confidence statements for the full **q2-gglasso** workflow, where the covariance is computed after compositional transformations and the fitted model may additionally include adaptive weights, multiple coupled graphs, or a sparse plus low-rank decomposition. For this reason, the network outputs in this tutorial are reported as selected conditional dependence structures under the stated transformation, penalty path, and eBIC choice, not as formally tested microbial interactions.

(sec:gglasso-complexity)=
## Computational complexity

Constructing a covariance matrix from a dense transformed table with $n$ samples and $p$ features requires $O(np^2)$ operations and $O(p^2)$ storage. The **GGLasso** implementation used by **q2-gglasso** solves the graphical models by alternating direction method of multipliers (ADMM). For a dense single-graph or latent-variable fit, the matrix eigendecomposition in each ADMM iteration costs $O(p^3)$ operations, with $O(p^2)$ storage {cite:p}`Schaipp2021`. The low-rank update in the latent model also requires a spectral decomposition. The single graphical lasso without latent variables can instead be separated into blocks. If their sizes are $p_1,\ldots,p_B$, the decomposition replaces the cubic part of one iteration by $O(\sum_{b=1}^{B}p_b^3)$; it offers little reduction when most variables belong to one large block. For $K$ related graphs of the same dimension, the corresponding dense matrix updates cost $O(Kp^3)$ per iteration and require $O(Kp^2)$ storage. The number of iterations depends on the penalty parameters, data, and convergence tolerances.

Model selection solves these problems repeatedly over the specified penalty grid. Small penalties can yield dense graphs and large connected blocks, so both individual fits and an extensive grid may be slow. QIIME 2 adds the cost of loading and writing artifacts and recording provenance to the solver time. These costs should be distinguished from ADMM iterations when comparing runtime across command-line workflows.
