## High-dimensional elevation prediction with q2-classo

Elevation prediction starts from the top-300 ASV table with the R3 concomitant least-squares formulation. Fifteen ASVs are absent from all 39 training samples and occur only in the held-out samples. We exclude these ASVs before fitting and apply the same 285-feature list to the held-out table before CLR transformation. This training-only support filter is also used for the classification examples below. The prevalence-rank ASV labels are retained, and the full 300-feature table is unchanged for the full-data network analyses. Let $Z\in\mathbb{R}^{n\times 285}$ denote the CLR-transformed ASV design matrix. The ASV-only model is

```{math}

y = \beta_0 \mathbf{1}_n + Z\beta+ \varepsilon,
    \qquad \mathbf{1}_{285}^{\top}\beta= 0,
```

where $y\in\mathbb{R}^n$ is the elevation response. To evaluate how much additional information is carried by measured non-compositional sample variables, we also fit the joint model

```{math}

y = \beta_0 \mathbf{1}_n + Z\beta+ U\gamma_{\mathrm{cov}} + \varepsilon,
    \qquad \mathbf{1}_{285}^{\top}\beta= 0,
```

where $U\in\mathbb{R}^{n\times 6}$ is the appended covariate design and $\gamma_{\mathrm{cov}}\in\mathbb{R}^6$ are ordinary regression coefficients. The zero-sum constraint is therefore imposed only on the ASV coefficient vector $\beta$. The covariate panel contains log-transformed extract concentration, pH, electrical conductivity, log-transformed amplicon concentration, total organic carbon, and depth. It is deliberately compact: it retains interpretable biomass, soil-chemistry, salinity, sequencing-yield, carbon, and sampling-depth information, while avoiding the more redundant humidity--temperature--cover block visible in the metadata correlation matrix in Figure {ref}`S1 <fig:atacama-covariates-overview>`.

Because penalized prediction is sensitive to the scale of every design column, the metadata block is constructed on the training set before it is appended to the CLR ASV table. Following Stadler et al. for CLR-transformed design matrices {cite:p}`stadler2024predictive`, we add non-compositional covariates as unconstrained columns to the log-contrast design. The metadata variables are transformed where appropriate and missing entries are imputed from training-set summaries. The ASV CLR columns are not rescaled. Instead, only the appended covariates are centered and scaled to a comparable column length. Let $Z_{\mathrm{train}}$ denote the 285-column CLR ASV training matrix and define

```{math}

a = \operatorname{median}_{1\le k\le 285}
        \left\lVert Z_{\mathrm{train},\cdot k}\right\rVert_2 .
```

Let $R$ denote the transformed and imputed metadata matrix before column rescaling. For each covariate column $j$, let

```{math}

m_j = n_{\mathrm{train}}^{-1}\mathbf{1}^{\top}R_{\mathrm{train},\cdot j},
    \qquad
    s_j = \left\lVert R_{\mathrm{train},\cdot j}
          - m_j \mathbf{1}\right\rVert_2,
    \qquad
    U_{\cdot j} =
        a\,\frac{R_{\cdot j} - m_j \mathbf{1}}{s_j}.
```

Thus each appended column in $U$ has training-set Euclidean norm $a$, the median column norm of the ASV block, while $Z$ remains exactly the CLR design used in the ASV-only model. The already scaled covariates are supplied to `classo add-covariates` with `--p-no-rescale`, so that QIIME 2 does not re-estimate scaling constants after the train--test split has been defined. After this preprocessing, ASV columns and appended covariate columns all carry penalty weight 1.

The augmented model estimates a joint prediction rule and does not decompose microbial and non-microbial contributions to elevation. Extract concentration is strongly correlated with elevation in the training data ($r=0.88$), and pH and electrical conductivity are also moderately correlated with elevation ($r=-0.60$ and $r=-0.49$). The comparison therefore illustrates the joint log-contrast formulation implemented by **q2-classo**: microbial log-contrast coefficients and ordinary covariate coefficients can be estimated in one penalized regression problem, while keeping the compositional constraint restricted to the microbial block.

## High-dimensional vegetation classification with q2-classo

The same training-supported 285-column CLR ASV table is used for the vegetation classification task in Section {ref}`S2.1 <sec:lowdim-classification>`. The response is the binary `vegetation` metadata column, and the train--held-out split is again the same 39/14 split used throughout the Atacama examples. The response, samples, transformation, zero replacement, and class encoding are held fixed; the candidate ASV set is enlarged from 15 to 285 predictors selected from the top-300 feature table by training-set support.

We fit two C1 **q2-classo** classifiers. Five-fold cross-validation with the 1SE rule provides a prediction-oriented baseline, whereas stability selection with $B=100$ subsamples, target support size $q=10$, and selection threshold 0.4 evaluates whether a smaller set of ASVs is repeatedly selected under resampling in the high-dimensional design.

## High-dimensional association networks with q2-gglasso

Conditional association networks are estimated from the same top-300 ASV table. The q2-classo analyses use measured covariates as responses or predictors in log-contrast prediction problems. The q2-gglasso analyses estimate conditional ASV associations after the CLR-transformed table has been converted to a scaled covariance matrix. All fits in this section use the 53-sample top-300 ASV table, CLR transformation with pseudocount 1, the scaled covariance estimator with likelihood normalization by $n=53$, and eBIC model selection with $\gamma=0.25$. The ASV-only graph has 300 nodes, and the mixed graph has 306 nodes after appending the six measured covariates; this high-dimensional setting motivates the stronger graph-size penalty relative to the top-15 ASV analysis. The value remains a user-defined model-selection choice, with larger values favoring sparser eBIC solutions.

**Single graphical lasso:**

The empirical CLR correlation matrix is dense and strongly block-structured, reflecting the shared environmental gradients also evident in the prediction analyses. The single graphical lasso (SGL) estimates a sparse ASV-only conditional association network. eBIC selects $\lambda_1=0.65$ and retains 408 ASV--ASV edges among 228 connected ASVs ({ref}`S15 <fig:top300-gglasso-networks>`, upper right). The fitted graph retains several local correlation blocks as conditional association modules.

**Example:**

```bash
# CLR transformation and scaled covariance construction
qiime gglasso transform-features \
    --i-table atacama-top300-prevalence-53-table.qza \
    --i-taxonomy taxonomy.qza \
    --o-transformed-table atacama-top300-53-clr-pseudocount1.qza

qiime gglasso calculate-covariance \
    --i-table atacama-top300-53-clr-pseudocount1.qza \
    --o-covariance-matrix atacama-top300-53-clr-pseudocount1-correlation.qza

# ASV-only single graphical lasso
qiime gglasso solve-problem \
    --i-covariance-matrix atacama-top300-53-clr-pseudocount1-correlation.qza \
    --p-n-samples 53 \
    --p-no-latent \
    --p-lambda1-path 1.00 0.95 0.90 0.85 0.80 0.75 0.70 0.65 0.60 0.55 0.50 0.45 0.40 \
        0.35 0.30 \
    --p-gamma 0.25 \
    --o-solution atacama-top300-53-clr-pseudocount1-sgl-ebic-gamma025.qza
```

**Mixed graphical model:**

Measured sample variables are included directly in the graphical model. The covariate block contains elevation, pH, soil relative humidity, soil temperature, vegetation cover, and log-transformed extract concentration. These variables summarize the main environmental axes in the Atacama metadata, and several of them were also selected or implicated in the q2-classo prediction analyses. In the mixed graph, q2-gglasso first appends scaled metadata columns to the transformed ASV table, then estimates one sparse graph over the 300 ASVs and six measured covariates.

The covariate penalty is set to 0.05. This deliberately small penalty reflects the low dimensionality and high prior relevance of the measured covariates: there are only six of them, and each plausibly acts on many ASVs along the Atacama transect. With $\gamma=0.25$, eBIC selects $\lambda_1=0.70$. The selected mixed graph contains 146 ASV--ASV edges, 1122 ASV--covariate edges, and 14 covariate--covariate edges. The reduction from 408 to 146 ASV--ASV edges indicates that a substantial part of the ASV-only conditional association structure is aligned with measured environmental variation ({ref}`S15 <fig:top300-gglasso-networks>`, lower left). This is consistent with the classo results: for example, elevation and extract concentration were already strongly predictive in the log-contrast regression task, and ASV-14 showed the same broad inverse elevation-associated pattern in the low-dimensional example.

## Latent variable graphical model and robust PCA

The latent-variable graphical model estimates unmeasured shared sample variation from the ASV table alone. Its sparse component represents the ASV conditional association network, while the low-rank component absorbs dense shared variation that can be summarized by a small number of latent directions.

The latent fit fixes $\lambda_1$ at the SGL-selected value 0.65 and selects $\mu_1$ over a grid. With $\gamma=0.25$, eBIC selects $\mu_1=15$, giving a rank-2 low-rank component and 376 sparse ASV--ASV edges among 222 connected ASVs. Compared with the ASV-only SGL, the latent model removes 32 sparse edges while preserving the major local association blocks ({ref}`S15 <fig:top300-gglasso-networks>`, lower right). The selected rank is not specified by hand; it is the rank obtained at the selected $\mu_1$ value.

**Example:**

```bash
# latent-variable graphical lasso
qiime gglasso solve-problem \
    --i-covariance-matrix atacama-top300-53-clr-pseudocount1-correlation.qza \
    --p-n-samples 53 \
    --p-latent \
    --p-lambda1-path 0.65 \
    --p-mu1-path 60 50 40 30 25 20 15 12.5 10 7.5 5 \
    --p-gamma 0.25 \
    --o-solution atacama-top300-53-clr-pseudocount1-slr-lambda065-mu-sweep-gamma025.qza
```

The q2-gglasso PCA visualizer uses the fitted latent solution and the CLR-transformed top-300 ASV table to obtain two robust principal-component coordinates for the 53 samples, and color the resulting ordinations by the measured Atacama covariates. This visualization does not recompute the graphical model; it summarizes the sample structure already encoded in the selected low-rank block.

**Example:**

```bash
qiime gglasso pca \
    --i-table atacama-top300-53-clr-pseudocount1.qza \
    --i-solution atacama-top300-53-clr-pseudocount1-slr-lambda065-mu-sweep-gamma025.qza \
    --m-sample-metadata-file atacama-top300-53-robust-pca-metadata-q2.tsv \
    --p-n-components 2 \
    --p-color-by elevation \
    --o-visualization atacama-top300-slr-rank2-robust-pca-color-by-elevation.qzv
```

The robust PCA display relates the latent graphical-model component to measured environmental structure ({ref}`S16 <fig:highdim-latent-covariates>`). Latent PC1 is strongly associated with elevation (Spearman $\rho=0.80$), log-transformed extract concentration ($\rho=0.77$), vegetation cover ($\rho=0.72$), soil temperature ($\rho=-0.71$), soil relative humidity ($\rho=0.59$), and pH ($\rho=-0.50$). Latent PC2 shows much weaker marginal associations with the same covariates. Latent PC1 captures a broad environmental sample gradient also visible in the regression, classification, and mixed graphical-model analyses. The interpretation remains descriptive because the latent directions are estimated from the ASV table alone and are identified by comparison with metadata after the fit.
