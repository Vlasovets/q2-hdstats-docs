# Statistical background

This section gives the statistical background for the **q2-classo** and **q2-gglasso** plugins: compositional data analysis, microbiome sequencing count tables and QIIME 2 artifacts, and the transformations used by the two plugin workflows. The remaining subsections describe the mathematical formulations of the implemented estimators in **q2-classo** and **q2-gglasso**. Table {ref}`S8 <tab:notation>` collects the symbols used throughout.

Command examples show non-default parameter settings. Omitted settings use the
registered defaults of the [pinned plugin versions](../reproducibility.md).
Inputs and outputs remain explicit; switches that disable unwanted analyses
are retained when they differ from the defaults.
