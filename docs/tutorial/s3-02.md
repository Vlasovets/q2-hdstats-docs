# Association-network estimation with **q2-gglasso**

Conditional association networks are estimated from the full filtered mOTU table using all $n=34$ samples, without a training--test split. An SGL estimate is compared with a latent-variable graphical model. Both use a scaled covariance matrix with likelihood normalization by $n=34$ (`--p-method scaled` and `--p-bias`) and the eBIC criterion in {eq}`eq:ebic`. The eBIC parameter $\gamma$ is user-defined and controls the additional penalty on graph size. We set the eBIC parameter $\gamma=0.1$. This penalty choice is specific to the present $p=60$, $n=34$ analysis.

(sec:metagenomics-sgl)=
## Microbial association network estimation with the single graphical lasso

The SGL estimates one sparse precision matrix for the mCLR-transformed mOTU table. Its non-zero off-diagonal entries define conditional mOTU associations, conditional on the other 58 mOTUs. The selected solution has $\lambda_1=0.25$, an interior point of the specified path, and 276 mOTU--mOTU edges ({ref}`S22 <fig:motus-gglasso-matrices>`, upper right). The full edge list is retained in the QIIME solution artifact, while the displayed matrix provides the more useful overview at this dimensionality.

**Example:**

```bash
# mCLR transformation and scaled covariance construction
qiime gglasso transform-features \
    --i-table motus-prev10pct.qza \
    --i-taxonomy motus-complete-taxonomy.qza \
    --p-transformation mclr \
    --o-transformed-table motus-60-mclr.qza

qiime gglasso calculate-covariance \
    --i-table motus-60-mclr.qza \
    --o-covariance-matrix motus-60-mclr-correlation.qza

# single graphical lasso with eBIC model selection
qiime gglasso solve-problem \
    --i-covariance-matrix motus-60-mclr-correlation.qza \
    --p-n-samples 34 \
    --p-no-latent \
    --p-lambda1-path 3 2 1.5 1.25 1 0.8 0.6 0.5 0.4 0.3 0.25 0.2 0.15 0.1 0.075 0.05 \
    --p-gamma 0.10 \
    --o-solution motus-60-mclr-sgl-ebic-gamma010.qza
```

(sec:metagenomics-slr)=
## Latent variable graphical model

The latent-variable model separates a low-rank component of unmeasured shared variation from the conditional mOTU network. It uses a CLR-transformed table with pseudocount 1, and jointly selects $\lambda_1$ and $\mu_1$ on explicit grids. At $\gamma=0.10$, eBIC selects $\lambda_1=0.25$ and $\mu_1=5$, both interior grid values, with a rank-one low-rank component and 248 sparse mOTU--mOTU edges. Of these, 116 also occur in the SGL network. The two transformations differ because the mCLR fit preserves zero entries whereas the latent fit requires a fully positive CLR table. The displayed graphs are complementary conditional-association summaries.

**Example:**

```bash
# CLR transformation for the latent-variable model
qiime gglasso transform-features \
    --i-table motus-prev10pct.qza \
    --i-taxonomy motus-complete-taxonomy.qza \
    --o-transformed-table motus-60-clr-pseudocount1.qza

qiime gglasso calculate-covariance \
    --i-table motus-60-clr-pseudocount1.qza \
    --o-covariance-matrix motus-60-clr-pseudocount1-correlation.qza

qiime gglasso solve-problem \
    --i-covariance-matrix motus-60-clr-pseudocount1-correlation.qza \
    --p-n-samples 34 \
    --p-latent \
    --p-lambda1-path 3 2 1.5 1.25 1 0.8 0.6 0.5 0.4 0.3 0.25 0.2 0.15 0.1 0.075 0.05 \
    --p-mu1-path 60 45 30 20 15 10 7.5 5 2.5 1 \
    --p-gamma 0.10 \
    --o-solution motus-60-clr-slr-ebic-gamma010.qza
```

The selected low-rank component is rank one. Consequently, it cannot yield a two-dimensional robust-PCA display: the q2-gglasso PCA visualizer requires two latent directions to plot PC1 against PC2. Instead, {ref}`S23 <fig:motus-latent-factor>` shows the single sample score obtained by projecting the CLR mOTU table onto its latent direction against the two available covariates. The score has only a weak monotone association with postnatal age (Spearman $\rho=-0.23$); its separation by maternal asthma is shown descriptively.
