# Bean-type classification with **q2-classo**

We predict bean type from the filtered species composition. To retain a small, genuinely held-out evaluation set, the data are split before transformation into 10 training samples (five per bean type at 0, 24, 48, 72, and 96 hours) and four held-out samples (one per bean type at 120 and 144 hours). This temporal split asks whether the early and intermediate fermentation profiles transfer to the final two time points. We apply CLR with a zero replacement of 0.5 separately to these two tables. The classifier is fitted with the C2 formulation at $\rho=0$, using the standard solver and the plugin's default CV seed, only to the training table with five-fold cross-validation; the 1SE rule selects the same penalty as the minimum-error rule. Stability selection is not used because its half-sample resamples contain only five training samples, and the restricted $q=4$ path did not converge reliably.

**Example:**

```bash
# Transform training and held-out tables separately.
qiime classo transform-features \
    --i-features bracken-species-prev14-total50k-train.qza \
    --o-x bracken-species-prev14-total50k-train-clr05.qza

qiime classo transform-features \
    --i-features bracken-species-prev14-total50k-test.qza \
    --o-x bracken-species-prev14-total50k-test-clr05.qza

qiime classo classify \
    --i-features bracken-species-prev14-total50k-train-clr05.qza \
    --m-y-file metadata.tsv \
    --m-y-column bean_type \
    --p-no-path \
    --p-no-stabsel \
    --p-huber \
    --p-no-refit \
    --o-result bracken-bean-type-train-clr05-c2-rho0-cv-no-refit-pr60.qza

qiime classo predict \
    --i-features bracken-species-prev14-total50k-test-clr05.qza \
    --i-problem bracken-bean-type-train-clr05-c2-rho0-cv-no-refit-pr60.qza \
    --o-predictions bracken-bean-type-train-clr05-c2-rho0-cv-no-refit-pr60-test-predictions.qza
```

Five-fold training cross-validation reaches a minimum classification error of 0.10 at $\lambda/\lambda_{\max}=0.32745$ (Figure {ref}`S25 <fig:bracken-cv>`). The selected penalized classifier retains five species: *Serratia rubidaea* and *Brevundimonas nasdae* have negative coefficients, whereas *Serratia marcescens*, *Komagataeibacter saccharivorans*, and *Klebsiella variicola* have positive coefficients. With the class encoding used here, positive scores correspond to Hybrid beans. The analysis retains the penalized coefficient vector at the CV-selected penalty; an unpenalized post-selection refit is not applied. Although refitting can reduce the shrinkage bias of an $\ell_1$-penalized estimator, its benefit for prediction depends on the selected design and task {cite:p}`lederer2013trust`. Retaining the penalized fit preserves the regularization selected on this small training set and avoids an additional estimation step. It classifies all 10 training samples and three of the four temporally held-out samples correctly; the 144 h Forasteiro sample has a borderline positive score of 0.020 (Figure {ref}`S26 <fig:bracken-penalized>`). Fermentation time is central to the setting, so the five species should not be read as causal bean-type markers or as a precise estimate of generalization performance.
