## Working on the docs without a cluster

**You do not need a local toolchain.** `.github/workflows/ci.yml` builds the
book on every push to `main` and every PR, deploys on push, and then verifies
that the live site carries that build's stamp. Edit markdown, push, read CI.

If you do want a local build:

```bash
pip install -r requirements.txt       # jupyter-book<2, sphinx<8, rediraffe
jupyter-book build docs --warningiserror
```

To regenerate the book's computed figures — **verified 2026-08-09 to work from a
clean clone with no cluster and no QIIME 2**:

```bash
pip install -r analysis/requirements-figures.txt
python analysis/scripts/make_docs_figures.py
```

The inputs live in `analysis/results/tables/` and `analysis/results/gglasso/`
(103 KB of TSV, committed for exactly this reason).

## Known defects, not yet fixed

These are all **offline-fixable** — they are prose and markdown.

1. **MGL chapter Step 1 does not run.** It filters on `[transect-name]`, which
   does not exist in the tier-1 metadata shipped with the plugin. The transect
   is recoverable from the sample-ID prefix (`BAQ…`/`YUN…`). Full detail and
   the measured replacements in `analysis/reports/mgl-verification.md`.
2. **Install instructions bypass the repo's own environment file.**
   `docs/chapters/01_installation/02_q2_gglasso.md` uses base-distribution +
   `pip install -r requirements.txt` with no `--no-deps`, while
   `q2-gglasso/environment-files/q2-gglasso-qiime2-2026.7.yml` solves everything
   in one conda transaction. The env file should be the primary path.
3. **Six chapters still open with boilerplate** (`## Overview` /
   "This tutorial demonstrates how to…"):
   `02_lowdim_gglasso/{02_sgl,04_adaptive_glasso,09_interpretation}.md`,
   `03_lowdim_classo/03_regression/00_index.md`,
   `03_lowdim_classo/04_classification/{00_index,02_trac}.md`.
4. **`06_multiple_graphical_lasso.md` has no figure.** A GGL vs FGL *schematic*
   is the honest choice — the page documents an interface that cannot close
   end-to-end, so a data figure would overstate it.
5. **`ph = 0` is a missing-value sentinel** in the Atacama metadata (8 samples,
   ≈2.8 SD below the mean) and feeds the classo regressions as a real value.
   Flagged in `04_highdim_atacama/05_classo_cv.md` and the classo reference
   page; the underlying data is unfixed.
